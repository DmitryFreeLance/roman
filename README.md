# REDLINE CLUB

Telegram-бот и Mini App для мультигруппового автомобильного маркетплейса.

## Что реализовано

- каталог магазинов и товаров в контексте Telegram-группы;
- роли покупателя, продавца, владельца группы и супер-админа;
- прямой P2P-сценарий заказа без приёма денег площадкой;
- формула итоговой цены из цены продавца и двух комиссий;
- начисление комиссионного долга после завершения сделки;
- автоматическая блокировка публикаций и продаж при превышении лимита;
- отзывы и рейтинги в схеме данных;
- создание темы «Магазин» и публикация карточек через Telegram Bot API;
- групповая закупка: бронь → сбор порога → новая цена → 24–48 часов
  на оплату → подтверждение продавца → рассылка срока поставки;
- список покупателей и контактов для организатора;
- проверка подписи Telegram Mini App `initData`;
- адаптивный интерфейс с демонстрационными сценариями всех ролей.

## Структура

- `app/` — Mini App на React/Next.js;
- `bot/` — Java 21 + Spring Boot API и Telegram webhook;
- `bot/src/main/resources/db/migration/` — схема PostgreSQL;
- `docker-compose.yml` — PostgreSQL и bot API.

## Локальный запуск Mini App

```bash
npm install
npm run dev
```

## Запуск бота и PostgreSQL

1. Скопируйте `.env.example` в `.env` и заполните значения.
2. Укажите публичный HTTPS-адрес backend в `PUBLIC_BASE_URL`.
3. Запустите:

```bash
docker compose up --build
```

Webhook принимает обновления на
`/api/telegram/webhook/{TELEGRAM_WEBHOOK_SECRET}`. Для production один раз
вызовите Telegram `setWebhook`, передав тот же секрет в `secret_token`.

## Mini App API

Mini App передаёт оригинальную строку `Telegram.WebApp.initData` в заголовке
`X-Telegram-Init-Data`. Backend проверяет HMAC-подпись и срок действия перед
каждым изменением данных.

Для подключения интерфейса к backend задайте:

```bash
NEXT_PUBLIC_API_URL=https://your-bot-api.example.com
```

Оплата товаров и комиссий выполняется напрямую между участниками. Площадка
хранит только статусы сделок и бухгалтерский счётчик комиссионного долга.
